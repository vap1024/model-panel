# Changelog

## 0.1.0

- Added validated JSON route configuration and environment expansion.
- Added parallel route execution, ping support, retries, and metadata collection.
- Added answer fingerprinting and independent voice counts.
- Added deterministic synthesis, markdown reporting, and command line tools.
- Added offline fake routes, demo, documentation, and automated checks.
- Added PANEL_META measurements, deduplication during synthesis, and setuptools packaging with pyproject.toml.
- Agreement is reported as n/a when fewer than two independent voices remain; empty-token answers are compared by normalized text.
